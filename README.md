## Project summary

Crime data is often spread across different sources and may be organized in different formats, making it difficult for users to search and analyze. Our project will collect publicly available crime data, organize it into a consistent format, and store it in a centralized database. Users will be able to explore crime incidents through an interactive map and search or filter incidents by location, crime type, date, and time period. The application will also allow users to select an area and analyze the incidents within that area to identify possible crime patterns using statistics and visualizations.
